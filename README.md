# FlowMamba

Baseline Zeek packet-capture pipeline in Python for producing packet-flow-encoder-ready input.

## What this baseline includes

- Zeek runner for live interface capture or offline pcap processing
- `conn.log` parser for canonical connection-level fields
- Flow feature vector builder with:
  - numeric flow metrics (min-max normalized)
  - protocol one-hot features (`tcp`, `udp`, `icmp`, `other`)
- CLI to run the pipeline end-to-end and emit JSON payload for a flow encoder

## Structure

- `flowmamba/zeek_pipeline.py` – capture + parse + encode
- `flowmamba/cli.py` – command-line entrypoint

## Usage

### 1) Offline pcap

```bash
python -m flowmamba.cli \
  --pcap /path/to/input.pcap \
  --output-dir /path/to/output
```

### 2) Live interface

```bash
python -m flowmamba.cli \
  --interface eth0 \
  --output-dir /path/to/output
```

Output files:
- `conn.log` generated by Zeek
- `encoder_input.json` containing:
  - `feature_names`
  - `vectors` (normalized model-ready numeric input)
  - `metadata` (flow context for traceability)
